# InteractiveMessage

A status message banner for `info`, `success`, `warning`, and `error` feedback, with optional icon, dismiss button, loading spinner, and action button.

The import below assumes a file directly under `src/`, after copying the source templates. Adjust the relative path for the target page.

```ts
import { InteractiveMessage } from './components/cobalt-extensions';
```

## Variations

Use the `variation` prop to communicate semantic meaning. The icon and action button color are automatically derived from the variation.

| `variation` | Icon           | Use case                               |
| ----------- | -------------- | -------------------------------------- |
| `info`      | `info`         | General information (**default**)      |
| `success`   | `check_circle` | Operation completed successfully       |
| `warning`   | `warning`      | Potential issue, user attention needed |
| `error`     | `error`        | Operation failed                       |
| `feature`   | `star_circle`  | New feature highlight                  |
| `primary`   | `info`         | Primary branded message                |
| `secondary` | `info`         | Neutral secondary message              |

## With Action Button

Provide both `actionLabel` and `onAction` to render an action button inside the message. The button's color type is automatically matched to the `variation`.

## With Dismiss

Provide `onDismiss` to render a close icon on the right side. When clicked it calls the callback — the caller is responsible for removing the component from the tree.

## With Loader

Set `withLoader={true}` to replace the variation icon with a spinner. Use this while an async operation is in progress.

- Left: `withLoader={false}` — shows variation icon (default)
- Right: `withLoader={true}` — shows Cobalt spinner

<Example id="extensions.interactivemessage.004" />

## Block Layout

Set `block={true}` when the message content spans multiple lines. This aligns the icon to the top and stacks content vertically.

- `block={false}` — icon and text are vertically centered in a single row (default)
- `block={true}` — icon anchored to top, content can wrap freely

<Example id="extensions.interactivemessage.005" />

## Banner vs Floating

Use the `type` prop to switch between `'banner'` (full-width, anchored to its container) and `'floating'` (inline, sizes to its content). The default renders without a `type`, deferring to Cobalt's component default.

- `type="banner"` — spans the full width of its parent container
- `type="floating"` — width follows the content

## Props

| Prop              | Type                                                                                   | Default                   | Description                                                          |
| ----------------- | -------------------------------------------------------------------------------------- | ------------------------- | -------------------------------------------------------------------- |
| `variation`       | `'info' \| 'success' \| 'warning' \| 'error' \| 'feature' \| 'primary' \| 'secondary'` | `'info'`                  | Semantic style — controls icon and action button color               |
| `type`            | `'banner' \| 'floating'`                                                               | —                         | Message layout type (`'banner'` = full width, `'floating'` = inline) |
| `actionLabel`     | `string`                                                                               | —                         | Label for the action button                                          |
| `onAction`        | `() => void`                                                                           | —                         | Action button click handler. Button only renders when provided.      |
| `isActionLoading` | `boolean`                                                                              | `false`                   | Shows a loading spinner on the action button while in-flight         |
| `onDismiss`       | `() => void`                                                                           | —                         | Close icon click handler. Icon only renders when provided.           |
| `withLoader`      | `boolean`                                                                              | `false`                   | Replaces variation icon with a spinner                               |
| `block`           | `boolean`                                                                              | `false`                   | Aligns icon to top and stacks content vertically                     |
| `children`        | `ReactNode`                                                                            | —                         | Message body content                                                 |
| `data-qa`         | `string`                                                                               | `'interactiveMessage'`    | QA selector attribute                                                |
| `data-component`  | `string`                                                                               | `'WFMInteractiveMessage'` | Component identifier                                                 |
