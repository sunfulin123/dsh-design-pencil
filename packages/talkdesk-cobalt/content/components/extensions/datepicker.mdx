# DatePicker

A date input that opens a Cobalt calendar popup and returns a plain JS `Date` — no manual `{ year, month, day }` conversion required.

The import below assumes a file directly under `src/`, after copying the source templates. Adjust the relative path for the target page.

```ts
import { DatePicker } from './components/cobalt-extensions';
```

## Basic Usage

The minimal setup requires only `value` and `onChange`. The input shows the selected date formatted as `MMMM D, YYYY` (e.g. "April 22, 2026"), and the calendar opens when the user clicks the field.

## With Label and Required

Use `label` to render a visible field label above the input. Combine with `isRequired` to append the required asterisk — this follows the same pattern as other extension form fields.

- `label` — text shown above the input
- `isRequired={true}` — adds the required marker next to the label

<Example id="extensions.datepicker.002" />

## Sizes

The `size` prop controls the height of the input trigger. Use `medium` (default) for standard form layouts; use `small` for dense toolbars and filter bars.

- Top: `size="small"` — compact height
- Bottom: `size="medium"` — default, standard form height

<Example id="extensions.datepicker.003" />

## Full Width

Set `isFullWidth={true}` to stretch both the trigger input and the popup to fill their container. Useful when the date picker sits inside a column or a form that controls its own width.

<Example id="extensions.datepicker.004" />

## Without Calendar Icon

Set `hasIcon={false}` to render the trigger as a plain input without the calendar icon prefix. Use this when the context makes the field type obvious or when the icon would clutter a dense layout.

<Example id="extensions.datepicker.005" />

## Custom Display Value

Pass `displayValue` to override the formatted string shown in the input with a static value. For a dynamic formatter that reacts to every date change, use `formatDate` instead.

- Left: `displayValue` — a pre-computed string passed directly to the input
- Right: `formatDate` — a formatter function called on each selected date, here producing a `DD/MM/YYYY` locale string

<Example id="extensions.datepicker.006" />

## Validation States

Use `variation` to apply a coloured border that signals a validation outcome. Combine with `label` and helper text in the parent form to guide the user.

- Left: `variation="error"` — red border, indicates an invalid or missing value
- Right: `variation="warning"` — yellow border, indicates a value that may need attention

<Example id="extensions.datepicker.007" />

## Disabled Days

Pass an array to `disabledDays` to prevent specific dates or ranges from being selected. Each entry is either an exact `{ year, month, day }` object or a `{ start?, end? }` range object.

- First calendar: individual days disabled
- Second calendar: a date range disabled

<Example id="extensions.datepicker.008" />

## Props

## Popup Position

Use `direction` and `origin` to control where the calendar popup opens relative to the trigger input. `direction` sets which side of the input the popup appears on; `origin` sets which corner of the popup aligns to the trigger. Both accept a `CardinalPoint` value such as `'N'`, `'SE'`, `'NW'`, etc.

The default `direction="SE" origin="SW"` opens the popup below and to the right of the input. Use `direction="NE" origin="NW"` when the field is near the bottom of the viewport so the calendar opens upward instead.

<Example id="extensions.datepicker.009" />

## Helper Text

Pass `description` to show neutral helper text below the input. Requires `label`. The text is styled in neutral grey and persists regardless of `variation`.

<Example id="extensions.datepicker.010" />

## Calendar Options

Use `isHighlightToday` to mark today on the calendar. Pass `highlightedDays` to accent specific dates without selecting them. Use `weekStart={1}` to start the week on Monday. Restrict the year dropdown with `availableYears`.

<Example id="extensions.datepicker.011" />

## Localised Calendar

Pass `months` and `weekdays` to fully localise the calendar header labels. `months` is an object mapping month numbers 1–12 to strings; `weekdays` is a 7-element array starting from Sunday.

<Example id="extensions.datepicker.012" />

## Props

| Prop               | Type                     | Default           | Description                                                                                                                             |
| ------------------ | ------------------------ | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `value`            | `Date \| null`           | —                 | Currently selected date. Pass `null` to show no selection.                                                                              |
| `onChange`         | `(date: Date) => void`   | —                 | Called when the user picks a date.                                                                                                      |
| `label`            | `string`                 | —                 | Label text rendered above the input.                                                                                                    |
| `isRequired`       | `boolean`                | `false`           | Shows a required asterisk next to the label (requires `label` to be set).                                                               |
| `placeholder`      | `string`                 | —                 | Placeholder text in the input when no date is selected.                                                                                 |
| `size`             | `'small' \| 'medium'`    | `'medium'`        | Input height.                                                                                                                           |
| `isFullWidth`      | `boolean`                | `false`           | Stretches the input and popup to fill the container width.                                                                              |
| `hasIcon`          | `boolean`                | `true`            | Shows the calendar icon prefix on the input.                                                                                            |
| `displayValue`     | `string`                 | —                 | Overrides the formatted date string in the input with a static value.                                                                   |
| `formatDate`       | `(date: Date) => string` | —                 | Formats the selected date into the input string. Takes precedence over the default `MMMM D, YYYY` format; overridden by `displayValue`. |
| `variation`        | `'error' \| 'warning'`   | —                 | Applies a coloured validation border to the input group.                                                                                |
| `description`      | `string`                 | —                 | Helper or validation message rendered below the input (requires `label`).                                                               |
| `direction`        | `CardinalPoint`          | `'SE'`            | Direction the calendar popup opens relative to the trigger.                                                                             |
| `origin`           | `CardinalPoint`          | `'SW'`            | Corner of the popup that aligns to the trigger anchor point.                                                                            |
| `availableYears`   | `number[]`               | ±3 from today     | Year list shown in the calendar's year selector.                                                                                        |
| `disabledDays`     | `DaysType`               | —                 | Days or ranges that cannot be selected.                                                                                                 |
| `highlightedDays`  | `DaysType`               | —                 | Days highlighted without being selected.                                                                                                |
| `isHighlightToday` | `boolean`                | `false`           | Highlights today's date on the calendar.                                                                                                |
| `weekStart`        | `0 \| 1`                 | `0` (Sunday)      | First day of the week. `1` = Monday.                                                                                                    |
| `months`           | `Record<1–12, string>`   | English names     | Custom month name labels.                                                                                                               |
| `weekdays`         | `string[]`               | English names     | Custom weekday name labels.                                                                                                             |
| `data-qa`          | `string`                 | —                 | QA selector. Also used as prefix for `-input` and `-calendar` child selectors.                                                          |
| `data-component`   | `string`                 | `'WFMDatePicker'` | Component identifier attribute.                                                                                                         |
