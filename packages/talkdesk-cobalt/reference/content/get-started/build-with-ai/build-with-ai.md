# Build with AI in Synapse Design

Use the selected runtime's bundled `synapse-design-html` Skill resources: `references/cobalt-workspace.md` owns the three build modes, project creation, app/page registration and review workflow; `references/cobalt/INDEX.md` indexes local design and component reference content.
