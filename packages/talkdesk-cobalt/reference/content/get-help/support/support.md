# Support

## Guidance

We want to share the guidelines to successfully communicate with the Cobalt team.

## Exploring the documentation

Whatever your need is, you should always start by exploring this documentation guideline first. It might also be
helpful to check out the [React documentation](https://prd-cdn-talkdesk.talkdesk.com/cobalt/docs/index.html?path=/docs/introduction-docs--page).

## Asking a question

If you have any questions for the Cobalt team, please submit them on our Slack channel
[#eng-sme-cobalt](https://talkdesk.slack.com/archives/C79STTSLT) (formerly #cobalt-support).

## Asking for documentation

If you want to ask for documentation, share your need on [#eng-sme-cobalt](https://talkdesk.slack.com/archives/C79STTSLT) (formerly #cobalt-support)
first. Please add to this page if the Cobalt team agrees with the documentation needed.

## Reporting a bug

If you want to report a Bug to Cobalt Team, first also confirm the need for this on our Slack channel
[#eng-sme-cobalt](https://talkdesk.slack.com/archives/C79STTSLT) (formerly #cobalt-support) to avoid creating unnecessary issues.

If the Cobalt team agrees with the bug need, please fill out
[this form](https://talkdesk.atlassian.net/secure/CreateIssueDetails!init.jspa?labels=Writing\&labels=support\&issuetype=3\&pid=14300\&assignee=5c572f5f7e444742bb2497e6).

## Checking Cobalt board

You can access our open Cobalt board whenever you need to take a look at what the Cobalt Team is doing.

## Submitting a request

If you want to submit a specific request to the Cobalt team, first share your need on
[#eng-sme-cobalt](https://talkdesk.slack.com/archives/C79STTSLT) (formerly #cobalt-support). If the Cobalt team agrees with the need, you can use
the [Cobalt Requests](https://talkdesk.atlassian.net/secure/CreateIssueDetails!init.jspa?labels=Design\&labels=support\&issuetype=3\&pid=14300\&assignee=61ead92398cd610070722d08)
board to create a **request** issue type and the associated labels.

Remember to fit your issue into one of the following categories:

* New features, components, or patterns
* Improvements

## Asking for a design review

If you want to ask for a design review please follow this
[documentation](https://talkdesk.atlassian.net/wiki/spaces/UX/pages/1103662259/Design+Reviews).

1. Add or update the cover with a "Design Review"
2. Go to the [Cobalt support and design-review form page](https://talkdesk.atlassian.net/secure/CreateIssueDetails!init.jspa?labels=Design\&labels=support\&issuetype=3\&pid=14300\&assignee=6143a2e1ea73af006a70b079)
3. Add the Summary as "**Design Review, (review title)**"
4. Fill the Description input with the **design-review link** and a **message for the reviewers**.
5. For Task Category select,
   1. **Review**
   2. **Design** if it requires cobalt review
   3. **Writing** if it requires product writing review
6. Add a **Due date**. Cobalt collects the due date to know your expectation, however, it is not guaranteed that it
   will be met.
