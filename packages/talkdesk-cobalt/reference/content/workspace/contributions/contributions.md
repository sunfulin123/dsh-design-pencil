# Contributions

## Guidance

If you have a different need or use case that is not described in the component or if you consider the need to
develop another new type of component that impacts the workspace, please feel free to reach out to the Workspace team
so that this need can be captured and understood and follow the instructions to
[request a new feature](https://talkdesk.atlassian.net/l/cp/gobpz09a).

Please, have into consideration that the Workspace components were the subject of an in-depth study and validation
process in order to work in perfect symbiosis with each other while, at the same time, responding to the product/app
use cases known today.
