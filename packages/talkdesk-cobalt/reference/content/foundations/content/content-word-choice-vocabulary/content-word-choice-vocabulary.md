# Vocabulary

## Guidance

Here you'll find a list of words/phrases that you should use in our UI to ensure consistency and, in
many cases, correctness.

| Do                           | Don't                       | Comments                                                                                                                                                                                                                  |
| ---------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Activity                     | Activity App                | Avoid using prefixes or suffixes (like "App") to refer to the Atlas apps.                                                                                                                                                 |
| Analyze                      | Analyse                     | Always use the American English variant.                                                                                                                                                                                  |
| Behavior                     | Behaviour                   | Always use the American English variant.                                                                                                                                                                                  |
| Blocklist                    | Blacklist                   | Contentious language.                                                                                                                                                                                                     |
| Canceled                     | Cancelled                   | Always use the American English variant.                                                                                                                                                                                  |
| Center                       | Centre                      | Always use the American English variant.                                                                                                                                                                                  |
| CSV                          | csv                         |                                                                                                                                                                                                                           |
| Email                        | E-mail                      |                                                                                                                                                                                                                           |
| Favorite                     | Favourite                   | Always use the American English variant.                                                                                                                                                                                  |
| internet                     | Internet Network            | "internet" is immediately understood by everyone. "Network" is slightly more technical and more ambiguous. **Note**: Please capitalize "internet" only at the beginning of a sentence (e.g., "Internet connection lost"). |
| Keypad                       | Dialpad Dial pad            |                                                                                                                                                                                                                           |
| License                      | Licence                     | Always use the American English variant.                                                                                                                                                                                  |
| No.                          | Nr.                         | "No." is the correct abbreviation for Number. "Nr." is the abbreviation used in Portuguese.                                                                                                                               |
| Organize                     | Organise                    | Always use the American English variant.                                                                                                                                                                                  |
| On a call                    | On call                     | "On call" means that someone is available for work at a moment's notice. It does not mean you are on a telephone call with someone.                                                                                       |
| Recognize                    | Recognise                   | Always use the American English variant.                                                                                                                                                                                  |
| Safelist                     | Whitelist                   | Contentious language.                                                                                                                                                                                                     |
| Setup (noun)                 | Setup (verb)                |                                                                                                                                                                                                                           |
| Set up (verb)                | Set up (noun)               |                                                                                                                                                                                                                           |
| Sign-in (noun or adjective)  | Login (noun or adjective)   | Correct: "You have one more sign-in attempt." Incorrect: "Please sign-in again."                                                                                                                                          |
| Sign in (verb)               | Log in (verb)               | Correct: "Please sign in again." Incorrect: "You have one more sign in attempt."                                                                                                                                          |
| Sign-out (noun or adjective) | Logout (noun or adjective)  |                                                                                                                                                                                                                           |
| Sign out (verb)              | Log out (verb)              |                                                                                                                                                                                                                           |
| Time zone                    | Timezone                    |                                                                                                                                                                                                                           |
| Traveled                     | Travelled                   | Always use the American English variant.                                                                                                                                                                                  |
| Try again                    | Retry                       |                                                                                                                                                                                                                           |
| You can't undo this action   | This action can't be undone | Active voice is usually better than passive voice.                                                                                                                                                                        |
| Wi-Fi                        | WiFi                        |                                                                                                                                                                                                                           |
