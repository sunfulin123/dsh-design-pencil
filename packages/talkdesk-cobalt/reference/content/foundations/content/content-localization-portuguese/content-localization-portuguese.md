# Portuguese

## Guidance

### Address users clearly

Use "you" and "your" to address users or use a "no point of view" approach.

### Avoid saying "sorry"

Use "sorry" only in error messages that result in severe problems for the user (for example, data loss,
the user can't continue to use Talkdesk, or the user must contact Support).

### Be concise, simple, and direct

Avoid unnecessary and redundant information. Avoid large blocks of text and long, complex sentences.
This will help users to be more efficient in their tasks and prevent cognitive overload.

### Be inclusive

Use gender-neutral language. A lot of Portuguese words are masculine, but there is *always* a way to be
as neutral as possible.

### Buttons should have verbs

Avoid unnecessary words and articles such as *a, o, as*, or *os.* **Use verbs.** Avoid saying "New" when
you're asking the user to create/add something.

### Do not translate Product names

Facebook Messenger is a name, and you should not translate that to Mensagens do Facebook, for example.
Not translating Product names is different from translating features and option names.

### English words

Use English words only if there is no translation or if they're known by the majority of the users. How
do you know that? If you're in doubt if the word is regularly used, just translate it. Common sense is
the key to this one.

### Punctuation isn't always necessary

Avoid using punctuation in places where it isn't necessary. Do not use periods in solitary sentences.
Use periods in multiple sentences.

### Use European Portuguese

Bad translations and/or a mix between European Portuguese and Brazilian Portuguese can cause a sense of
confusion and lack of confidence, as it is often something related to spam websites.

### Use positive language and an active voice

The subject of the sentence is the person or thing performing the action. With passive voice, it's
often hard for readers to figure out who's supposed to do something.

### Use the informal "you"

Always always always use "tu" instead of "você", preferably without having to say "tu" in the sentence.

### Write according to the latest Portuguese Language Orthographic Agreement

[Acordo Ortográfico da Língua Portuguesa](https://www.portoeditora.pt/lingua-portuguesa/conversor-acordo-ortografico)
