# Units

## Guidance

:::note
This page doesn't map to the current Foundations taxonomy (Tokens / Content / Accessibility) — flagged for review.
:::

Units are based on multiples of 4px that are applied and used within all Cobalt components.

The baseline is the smallest unit of space, with a defined scale of whole multiples of the baseline
providing additional options to group elements and establish hierarchy.
