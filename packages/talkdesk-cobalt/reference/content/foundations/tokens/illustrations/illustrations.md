# Illustrations

## Guidance

:::note
Sourced from the live Cobalt DS's Assets > Illustrations page. The asset library itself (the actual
illustration files) isn't reproduced here — this page carries the surrounding guidance only.
:::

Illustrations help transform complex ideas into a simple, visual interpretation. They should be
meaningful and reflect a user's context and emotional state.

## Asset list

The library includes illustration sets such as Badge (Champion, Climber, Favorite, Friendly, Podium,
Sprinter, Star — each with a placeholder variant), plus standalone illustrations: Bluetooth, Device,
Error, Empty, Identity, Success, Visual support, Forbidden, Set up, Outbound dialer, Conversation,
Call, Launch.

If you identify an illustration that should exist but doesn't, contact the Cobalt team to have it
included and documented.
