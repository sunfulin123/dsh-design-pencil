# Flags

## Guidance

:::note
Flags aren't their own token category in the spec's list — added here as a standalone page (rather
than folded into Iconography) since the asset set is large enough to bloat that page. Sourced from
the live Cobalt DS's Assets > Flags page.
:::

A flag is used to represent a political state.

## Definition

A flag can use the two-digit country code, the full name, or a common alias.

## Asset library

The library is organized alphabetically by country, from Afghanistan through Zimbabwe. The actual
flag SVG files aren't reproduced here — see the full set in
[Figma](https://www.figma.com/design/xBIZ1K28KembinPhdQecu4/4---%F0%9F%A7%AC-Assets?node-id=122-921\&t=ThfQ3lwgm9nV98h4-4).
