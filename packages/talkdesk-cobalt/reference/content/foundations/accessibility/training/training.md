## Guidance

:::note
Sourced from Cobalt's live Accessibility docs, which the Cobalt team has flagged as under review —
treat as a starting point, not settled guidance.
:::

Complying with accessibility standards and guidelines requires multiple teams and roles' effort.
Especially before performing an accessibility task and/or an accessibility audit, we highly recommend
completing these 5 courses:

* Introduction to Web Accessibility
* Get Started with Web Accessibility
* Learn Accessibility
* OAST Training Resources
* VPAT Training
