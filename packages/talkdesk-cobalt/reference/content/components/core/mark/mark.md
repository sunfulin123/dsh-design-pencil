# Mark

## Guidance

Used to highlight portions of a text such as a word or a phrase.

### Design

### Overview

**Mark** allows the user to determine parts to highlight inside content with different colors. It also can be used to get snippets of search results with matching keywords highlighted. It helps to improve an application’s search experience.

### Guidelines

#### Placement

It should always be placed inside Paragraphs and Microcopies.

#### Best practices

![Do example](/assets/mark/guidelines-do-s-don-ts-do.png)
*Do*
Use it inside Paragraphs

**Do:** Use it inside Microcopies.
![Do example](/assets/mark/guidelines-do-s-don-ts-do-2.png)

**Don't:** Don't use it on different typography components.
![Don't example](/assets/mark/guidelines-do-s-don-ts-dont.png)

![Don't example](/assets/mark/guidelines-do-s-don-ts-dont-2.png)
*Don't*
Don't mix different colors when highlighting.

### Behavior

#### Interaction

When the user marks a word or sentence inside a text the content is highlighted with the Mark component.

#### Dimensions

The width is always the same as the size of its content.
