# Most used templates

## Guidance

:::note
Moved here from Foundations — it originally came from the live Cobalt DS's Foundations > Structure
section, which doesn't exist in this site's taxonomy. It doesn't map to Layout Templates' own 6
categories (Authentication, Dashboard Layout, Detail Page, Error Pages, List View, Settings Layout)
either, but content-wise it belongs with Layout Templates far more than with Foundations — flagged for
review.
:::

For anyone looking for some great templates, look at some of the following. This collection includes
basic/empty page templates that can be used as a guide for creating your pages. After all, sometimes all
you need is to know where to start.

Using a template as a starting point for your user flows might be the quickest way to build a page
structure in seconds. There are plenty of decent templates here to quick-start your project, and all of
them are good-looking and functional.

---

## General layout

Usually, pages should have the main header on top, followed by a content area.

The header should be placed at the very top of the page and should be full-width.

The content area (unless stated otherwise, e.g. see **Headers** and **Tables** sections below) follows
the general spacing rules all around **L:24px / M:16px / S:12px**.

Check the following collection to learn more about page layouts in general.
