## Workspace chrome baseline

New projects use the owned Atlas redesign adaptation (`deb486689`, source revision `7014efc11`), not the older purple title bar shown in historical reference images. The generated `cobalt-source.json` records both the unchanged ai-docs snapshot and the Atlas reference/template hashes. The 44px title bar and 48px Dock share semantic light/dark chrome; the drawer and application area form a bordered surface. The business table remains square and flush inside it. Read `references/cobalt/workspace-chrome.md` for boundaries and review locators. Register apps/pages through the helper; do not recreate or restyle the shell from screenshots. Built-in IDs retain the canonical SVG URLs and drawer model: WFM is wfm, Conversations is conversation and Admin is admin. Omit iconName for built-ins; provided overrides are ignored. Custom apps still supply iconName. Never reconstruct the Dock mapping in main.tsx. There is no new-UI feature flag. Existing flags retain their individual simulated behavior. `add` never migrates an existing project's shell.

Top controls copy Atlas TitleBarButton/frame/Tooltip sources and load the actual official Cobalt dependencies. Preserve native Button state styling; never substitute solid secondary ramp fills for alpha tokens. Review search, status and profile controls against native Cobalt defaults, hover and expanded states in both schemes.
