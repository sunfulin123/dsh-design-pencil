## Prototype toolbar locators

The owned toolbar has no leading Prototype wordmark or brand icon. Both HTML and Workspace adapters copy the shared visual source: a 44px bar including its border, 32px desktop buttons and 36px narrow-screen buttons. The enabled-flags count is a compact badge, and menu rows keep a calm density. It uses three dropdowns for window size, page state and Feature flags; the business page never contains these controls. The prototype runtime owns responsive neutral light/dark chrome, keyboard focus, Escape/outside dismissal and viewport-clamped panels. Preserve its accessible names and stable test IDs when adapting a generated project.

Find the toolbar with `getByRole('region', { name: 'Prototype controls' })`. Triggers are `prototype-size`, `prototype-state` and `prototype-flags`, with accessible names `Window size`, `Page state` and `Feature flags`; open the trigger before finding an option. Panels have `prototype-<name>-panel`; close buttons have `prototype-<name>-close`. Size options use `prototype-size-fill`, `prototype-size-1920`, `prototype-size-1440`, `prototype-size-1280`, `prototype-size-1024`, `prototype-size-640` and `prototype-size-mobile`. State options use `prototype-state-success|loading|empty|error|partial|permission`. Human labels are Ready, Loading, Empty, Error, Partial and No access.

Flag switches use `prototype-flag-<flag-id>` with each documented flag label as its accessible name. `prototype-flags-reset` restores all flags. `prototype-reset` reloads prototype defaults and clears saved shell preferences. Current values have `prototype-size-value`, `prototype-state-value` and `prototype-flags-value`. Use `getByTestId` or scoped role/name locators. On every business route, select each state in the shell and check visible content and actions in `iframe[data-primary-frame]` before resetting to Ready. Confirm that Partial keeps the available content and No access hides restricted content and actions. Check 320/390/768/1024/1440 widths, keyboard operation, both themes and panel bounds before handing off.
