# Cobalt Workspace summary

Stage summary of [the Cobalt Workspace guide](../cobalt-workspace.md), used when the confirmed style id is `talkdesk-cobalt`. The HTML Skill's requirements, content states, layout judgement and evidence review still apply. Each paragraph names the section with the detail.

**Reference and Extensions** ([01](01-source-template-reuse-is-required.md), [03](03-read-the-bundled-cobalt-reference.md)): read `references/cobalt/INDEX.md`, `cobalt-reference/AI-INDEX.md` and the relevant local docs; never use an external docs checkout, remote search or guessed props. Extensions are source templates: never install, import or alias `@openpencil/cobalt-extensions`; resolve with the bundled lookup and `--id <component-ID> --read-source`, read all source, and adapt the copy in `src/components/cobalt-extensions/` with relative imports. For a full List page use the BasicTable + marketplace Toolbar recipe.

**Build mode and project** ([02](02-choose-the-build-mode.md), [04](04-create-and-extend-the-project.md)): default to Workspace with the copied shell and preserve its top bar, Dock, drawer, themes, size presets, feature flags and SDK stand-ins; skip it only for an explicitly standalone page or flow. Use the project the host prepared, or create one with `cobalt-project.mjs create --out <task-dir>/project --spec <apps.json>` (`add` for another app). Replace every scaffold page with business UI; register pages in `talkdesk-prototype.json`; route with `useWorkspaceState`/`workspace.navigate`; leave `src/workspace-shell/` and `src/prototype-runtime/` unchanged and add no ThemeProvider.

**Run and review** ([05](05-run-review-and-deliver.md)): install only with `synapse_design_prototype` `install`, never a shell package manager; report a real private-registry or VPN failure instead of substituting controls. Each route uses `usePrototypeScenario()` to implement Ready, Loading, Empty, Error, Partial and No access. Tables and lists are flush full-width surfaces with no outer card, border, shadow or horizontal parent padding; use the copied SidePanel for details. Write layout measurements before coding and verify table edges, toolbar and pagination centres and Dock icon centres numerically. Check every app through its Dock entry and drawer page, app switching, theme via the avatar menu and frame widths from 360px; target business controls with `frame: "iframe[data-primary-frame]"`.

**Deliver** ([05](05-run-review-and-deliver.md)): build with `run build` to `project/delivery/index.html`; run the final review with `--project <task-dir>/project --scope app`; hand off with entry `<task-dir>/project/delivery/index.html` and all built HTML/CSS/JS/assets in `files`. A Cobalt prototype never authorizes production changes.

**Before changing behaviour** ([06](06-local-cobalt-extensions-and-executable-recipes.md)–[11](11-protected-shell-and-popup-behavior.md)): read the recipe or wrapper source first; reuse copied dropdown, popup and calendar wrappers instead of document listeners; use the toolbar locators in section 07.
