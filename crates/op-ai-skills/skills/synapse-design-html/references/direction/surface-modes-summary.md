# Surface modes summary

Stage summary of [the surface-mode guide](surface-modes.md). Choose the mode from what success looks like on this surface, not from the company's industry: a developer tool's landing page is `Persuade`, its console `Operate`, its API guide `Read`; a lookbook is `Experience`, its checkout admin `Operate`.

On an `Operate` surface the visual world contributes only typography (one tuned sans plus monospace for data, a fixed `rem` scale with a `1.125–1.2` step, no fluid display headings), palette (restrained canvas, a secondary surface for chrome, semantic status tokens, full-saturation accent only for primary actions and selection), density (high data-ink ratio, `4px/8px` increments) and at most one signature move. Keep controls recognizable and motion task-appropriate. Dropdowns, popovers and tooltips inside clipping containers use `<dialog>`, the Popover API, `position: fixed` or portals.
